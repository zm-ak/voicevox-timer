# VOICEVOXタイマー（仮） UI/UX設計・画面仕様書

## 1. アプリケーション概要
「VOICEVOXキャラクターとの音声対話」を軸にし、実用的なタイマー機能をエンタメへと昇華させるAndroidアプリ。
「ポップ＆キュート」なデザインを基調とし、物理的なダイヤルを回すような直感的操作と、キャラクターとのコミュニケーション（音声・吹き出し）を両立させる。

## 3. 画面詳細設計

### 3.1 メイン画面（タイマー操作）
アプリの起点となる画面。円形ダイヤルを用いた直感的な時間設定と、キャラクターのリアクションを楽しむ設計。

#### UI仕様
* **キャラクター表示エリア:** 選択中のキャラクターの立ち絵を表示。ダイヤル操作中に目線が動く、設定時間に合わせて吹き出し（例：「3分にセットしたのだ！」）が出るなどの動的音声応答やリアクションを実装。
* **二重リングダイヤル:** 外周を「分」、内周を「秒」とした大きな円形ダイヤル。中央に現在の設定時間をデジタル表記。回す際に触覚フィードバック（Haptic）と小気味よい音を鳴らす。
* **音声入力ボタン:** 右下に控えめに配置。タップでスマホの標準音声認識を呼び出す。
* **稼働中タイマー一覧:** 画面最下部にボトムシート型（または横スクロール）で配置。並行稼働時の混乱防止のため、ラベル（タイマー識別名称）と残り時間を表示。

### 3.2 キャラクター選択・プレビュー画面
Google Play Asset Deliveryを利用したオンデマンドダウンロード方式や、アプリ内課金によるキャラクターボイスの追加解放を行う画面。権利表記を遵守しつつ、キャラクターの魅力を伝える。

#### UI仕様
* **プレビューエリア:** 上部に選択中キャラクターの大きな立ち絵と名前を表示。サンプルボイス再生ボタンを配置。背景色はキャラクターのテーマカラーに連動。
* **グリッド一覧:** 利用可能なキャラクターを顔アイコンで一覧表示。状態に応じたバッジを付与。
    * バッジなし：利用可能（「ずんだもん」等の基本キャラモデルなど初期同梱・DL済み）
    * クラウドアイコン（↓）：未ダウンロード（オンデマンドダウンロード対象）
    * 鍵アイコン：未解放（アプリ内課金による追加解放対象）
* **詳細・アクションエリア:** 選択中のキャラクターの権利元クレジットを明記（ライセンス・規約遵守のため必須）。状態に応じたアクションボタンを表示し、音声データの直接販売ではなく「アプリ内での機能解放（アンロック）」としての見せ方を徹底する。

## 4. 状態管理・通知・鳴動の仕様

### 4.1 バックグラウンド時の挙動
* **Foreground Serviceの利用:** アプリがバックグラウンドに移行した場合、OSの通知領域に常駐通知を表示する。
* **通知UI:** リアルタイムの残り時間表示と、「一時停止（スヌーズ）」「キャンセル」のアクションボタンを配置。アプリを開かずとも通知パネルから直接操作可能とする。

### 4.2 アラーム鳴動時の挙動
* **視覚演出の抑制:** 画面上の過度なアニメーションは行わず、バッテリー消費とユーザビリティに配慮したシンプルな時間経過表示とする。
* **音声主体の通知:** VOICEVOX Coreによるオフライン生成の動的な音声応答（キャラクターボイス）を主役として鳴動させる。
* **感情変化スヌーズ:** 停止（スヌーズ）回数に応じた立ち絵の表情変化とセリフの段階的な変化（優しく→焦り→怒り）を適用し、キャラクターとのコミュニケーション性を高める。
