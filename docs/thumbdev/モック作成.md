# タスク: Compose Multiplatformを用いたタイマーアプリの画面モック（UI骨組み）実装

あなたはAndroidおよびiOSのクロスプラットフォーム開発に精通したシニア開発者です。
提示する要件定義とUI設計に基づき、将来的なiOS展開を見据えた「Compose Multiplatform (Kotlin Multiplatform)」ベースのアプリの土台（画面モック）のソースコードを出力してください。

## 1. 開発環境・使用技術
* フレームワーク: Compose Multiplatform (KMP)
* 配信ターゲット: Android & iOS
* 画面遷移: Compose Multiplatform Navigation (`androidx.navigation:navigation-compose` ※マルチプラットフォーム対応版)
* 配置場所: 画面UIやナビゲーションのコードは、両OSで共通利用するため `composeApp/src/commonMain/kotlin` 内に配置される想定で記述してください。

## 2. 実装対象の画面と仕様
Android/iOS共通のUIとして、以下の2つの画面と相互の画面遷移を実装してください。

### ① メイン画面（MainScreen）
タイマー操作の起点となる画面です。縦に以下の要素を配置（Column）してください。
1. **キャラクター表示エリア (Card等):**
   * 仮のテキスト「ずんだもん立ち絵（通常）\n『3分セットしたのだ！』」を表示。
2. **二重リングダイヤルエリア (仮):**
   * ダイヤルを模した円形のBox（背景：ライトグレー、形状：CircleShape）。
   * 中央に現在の設定時間「03:00」を大きめのフォントでデジタル表記。
3. **キャラクター変更ボタン:**
   * タップすると「キャラクター選択画面」へ遷移。
4. **音声入力ボタン (FAB):**
   * 画面右下に配置（マイクアイコン）。
5. **稼働中タイマー一覧エリア (ボトムシート風または最下部カード):**
   * 仮のテキスト「稼働中のタイマー一覧 (カップ麺: 残り 2分30秒)」を表示。

### ② キャラクター選択画面（CharacterSelectScreen）
オンデマンドDLや課金解放を行う画面です。
1. **プレビューエリア (Card等):**
   * 仮のテキスト「選択中のキャラ：ずんだもん\n（サンプルボイス再生ボタン）」を表示。
2. **グリッド一覧 (LazyVerticalGrid):**
   * 3列のグリッドで、仮のキャラクターカードを6個程度表示。
   * カード内には以下のステータス（バッジ等）をテキストで表現：
     * キャラ0: 「利用可能」
     * キャラ1: 「未DL ☁️」
     * キャラ2以降: 「未解放 🔒」
3. **権利表記クレジット (Text):**
   * 画面下部に小さく「© 全真・SSS/ずんだもん」と明記。
4. **戻るボタン:**
   * タップすると「メイン画面」へ戻る。

## 3. 将来のiOS拡張（ネイティブ連携）を意識した設計要求
モックコードでは実際のロジック（タイマー、音声認識、通信等）は不要ですが、将来的にAndroid（Google Play Asset Delivery等）とiOS（On-Demand Resources等）で処理を切り分けられるよう、以下の配慮をコード内に含めてください。
* **プラットフォーム固有処理の抽象化（プレースホルダーの作成）:**
  音声認識（マイクボタン押下時）やキャラクターデータのダウンロード処理は、共通コード側でインターフェース（`interface`）として定義し、画面（Screen）クラスにはそれを外から注入（DI風に配置）できるような構造（またはダミーのクラスを呼び出す形）にしてください。

## 4. 出力コードへの要求
* `commonMain` にそのまま配置して、画面遷移がすぐに確認できる完全なKotlinコードを出力してください。
* マテリアルテーマ（Material 3ベース）を適用し、ポップ＆キュートなデザインの起点となるよう、角丸やカラーを適度にあしらってください。
