# VOICEVOXタイマー（仮）要件定義書
## 1. コンセプト
「VOICEVOXキャラクターとの音声対話」を軸に、実用的なタイマー機能をエンタメへと昇華させるAndroidアプリ。
## 2. デザインの方向性
 * **テーマ:** 「ポップ＆キュート」
 * キャラクターのテーマカラー（ずんだもんなら緑・黄色）を基調とし、親しみやすく、かつ操作が楽しいデザインを目指す。角丸のボタンや分かりやすいアイコンを多用する。
## 3. 実装機能一覧
### 【Ver 1.0：基本機能】
 * **タイマー・アラーム操作:** * UI（手入力、ダイヤル）による直感的な設定。
   * 音声入力（スマホの標準音声認識）による設定・停止。
 * **動的音声応答:** * 音声入力時の復唱（「3分セットしたのだ！」など）。
   * 状況に合わせたボイス通知。
   * VOICEVOX Coreによるオフライン生成。
 * **途中経過読み上げ:** 残り時間や状況のアナウンス。
 * **ラベル・複数タイマー管理:** タイマー識別名称の読み上げ、並行稼働時の混乱防止。
 * **感情変化スヌーズ:** 停止（スヌーズ）回数に応じた立ち絵の表情変化とセリフの段階的な変化（優しく→焦り→怒り）。
### 【将来の拡張候補：Ver 1.1〜】
 * **プリセット機能（おかえりタイマー）:** よく使う設定のワンタップ/ワンフレーズ呼び出し。
 * **睡眠導入モード:** ボイスのフェードアウト再生。
 * **スパルタ起床モード:** 指定セリフの音声入力クリアを条件とする停止機能。
 * **今日のひとこと機能:** アラーム停止時の天気や運勢通知。
## 4. システム構成・非機能要件
 * **OS:** Android (Google Play配信想定、Jetpack Compose推奨)
 * **音声合成:** VOICEVOX Core（Android組み込みによる完全オフライン生成）
 * **データ管理 (容量対策):** * 初期インストール時は「ずんだもん」等の基本キャラモデルのみ同梱。
   * 他キャラクターは「Google Play Asset Delivery」等を利用したオンデマンドダウンロード方式を採用。
## 5. 収益化・課金戦略
 * **広告表示 (AdMob):** * 画面下部バナー（誤タップ防止配置）。
   * リワード動画広告（任意視聴での一時的機能解放など）。
 * **アプリ内課金:** * 広告非表示オプション。
   * キャラクターボイス（モデルデータ）の追加解放（個別購入または一括パック）。
## 6. ライセンス・規約遵守
 * **クレジット表記:** アプリ内（設定画面やキャラクター選択画面等）に各キャラクターの権利元クレジットを明記。
 * **商用利用の確認:** 個人アプリでの商用利用（広告・課金）が許可されているキャラクターのみを実装対象とする。
 * **課金表現の適正化:** 音声データの直接販売ではなく、「アプリ内での機能解放（アンロック）」としての見せ方を徹底し、二次配布を防止する。
